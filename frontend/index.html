V-Track – Vehicle Entry & Exit Logging System

Welcome to V-Track. Use the navigation to:

  • Login – Admin login (required for Dashboard, Logs, Search)
  • Entry – Record vehicle entry
  • Exit – Record vehicle exit and see duration
  • Dashboard – Today's stats (entries, exits, currently parked)
  • Logs – View all logs with filters
  • Search – Search by vehicle number or date

Ensure the backend is running on http://localhost:8080.
